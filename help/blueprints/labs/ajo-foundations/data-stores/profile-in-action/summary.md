# 요약

이 랩에서는 데이터가 Adobe Experience Platform을 통해 흐르는 방식을 관찰하기 위해 데이터스트림을 구성하고 Postman을 사용하여 시뮬레이션된 웹 이벤트를 Edge Network으로 보냈습니다.

실시간 프로필에서 프로필이 만들어지고 세그먼트에 대한 자격이 있는지 확인하여 여러 플랫폼 서비스에서 이벤트를 처리했음을 확인했습니다. 또한 프로필이 Edge에 있는지 확인하고, 이벤트가 데이터 레이크에 저장되었는지 확인했으며, 예약된 일괄 업데이트 프로세스로 인해 프로필이 프로필 스냅숏 데이터 세트에 아직 표시되지 않았음을 확인했습니다.

이러한 단계를 통해 Adobe Experience Platform의 Edge, 실시간 프로필 및 데이터 레이크 레이어를 통해 이벤트가 이동하는 방법을 보여 주었습니다.
