# 실행 중인 프로필

## 필요 조건

>[!WARNING]
>
>이 실습을 시작하기 전에 아래 실습을 완료해야 합니다.

- [Postman 설치](../../postman-setup/postman-installation.md)

이 실습을 완료하지 않았다면 계속하기 전에 지금 완료하십시오.

## 랩 개요

이 비디오에서는 이 랩이 Edge Network에서 Adobe Experience Platform으로 웹 페이지 방문을 시뮬레이트하는 방법과 결과 프로필, 세그먼트 자격 조건 및 데이터 레이크 이벤트를 확인하는 방법에 대해 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3491061/)

## 학습 목표

이 연습에서는 Edge 소스에서 Adobe Experience Platform으로의 웹 페이지 방문을 시뮬레이션합니다. 이 실험실을 가지고 나면 뭘 가지고 가셔야 하죠?

- Adobe Experience Platform에서 데이터 스트림 만들기 및 구성
- Postman을 사용하여 Edge Network에 테스트 웹 이벤트 보내기
- 실시간 프로필에서 프로필 만들기 및 세그먼트 자격 확인
- 프로필이 Edge에 있지만 프로필 스냅샷 데이터 세트에 아직 없는지 확인
- 이벤트가 데이터 레이크에 저장되었는지 확인
