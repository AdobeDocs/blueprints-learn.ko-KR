# 오퍼 속성 만들기

## 목표

이 섹션에서는 표준 오퍼 XDM 스키마에 사용자 정의 XDM 필드를 추가합니다. 이러한 사용자 정의 필드는 순위, 정렬 및 자격 기준에 사용할 수 있습니다. 요청 장치로 반환되는 데이터일 수도 있습니다.

## 사용자 지정 장치 상위 개체 만들기

1. 필요한 경우 왼쪽 레일에서 **Decisioning** 메뉴 항목을 확장하고 **카탈로그**&#x200B;를 클릭합니다.
2. 기본적으로 &#39;오퍼&#39; 페이지가 표시됩니다. 오른쪽 상단의 **스키마 편집** 단추를 클릭합니다.

   ![오퍼 카탈로그 페이지의 스키마 편집 단추](assets/create-offer-attributes-edit-schema-button.png)

   >[!TIP]
   >
   >결과 페이지는 표준 XDM 스키마 편집기입니다. XDM을 사용하여 데이터 세트의 데이터 구조를 정의하는 것처럼 XDM을 사용하여 오퍼의 속성을 정의합니다.

   >[!NOTE]
   >
   >개인화된 오퍼 항목 - Experience Decisioning 스키마는 모든 오퍼에 적용되는 시스템 생성 표준 스키마입니다. 그러나 고유한 비즈니스 요구 사항을 충족하기 위해 이 스키마에 추가할 수 있습니다. 이는 이 섹션에서 수행하는 작업입니다.
   >
   >또한 오퍼 페이지를 통해 이 스키마를 이동하는 지름길입니다. 왼쪽 레일의 스키마 메뉴를 통해 이동할 수도 있습니다.

3. 스키마의 루트 수준 오른쪽에 있는 **+** 아이콘을 클릭하고 오른쪽 레일에 현재 표시된 &#39;필드 속성&#39; 메뉴를 사용하여 제공된 값으로 다음 필드를 채웁니다.
   - 필드 이름: **장치**
   - 표시 이름: **장치**
   - 유형 드롭다운: **개체**
   - 필드 그룹에 할당(이 값 입력): **오퍼 세부 정보**

   >[!NOTE]
   >
   >필드 그룹에 할당 드롭다운이 표시되지만 직접 텍스트 입력도 허용하므로 &#39;오퍼 세부 정보&#39; 텍스트를 입력합니다. 입력하면 &#39;오퍼 세부 사항(신규)&#39; 항목도 표시됩니다. 새 속성은 필드 그룹에 할당해야 하므로 이 단계에서는 오퍼 세부 사항이라는 새 필드 그룹을 효과적으로 만듭니다.

4. 아래 스크린샷과 같이 모든 속성이 작성되었는지 확인합니다.

   ![새 장치 개체에 대한 필드 속성이 채워짐](assets/create-offer-attributes-device-object-field-properties.png)

5. 모든 필드가 올바른지 확인한 후에는 &#39;필드 속성&#39; 메뉴(오른쪽 레일) 하단에 있는 파란색 **적용** 단추를 클릭하여 스키마에 적용된 변경 사항을 확인합니다.

![오퍼 스키마에 적용되는 장치 필드 그룹](assets/create-offer-attributes-device-object-applied.png)

>[!TIP]
>
>일반 XDM과 마찬가지로 사용자 지정 속성은 IMS 조직 고유의 네임스페이스, 즉 이 경우 imsorg 테넌트 ID 또는 &#39;dep&#39; 아래에 그룹화됩니다. 또한 이제 새 &#39;오퍼 세부 정보&#39; 필드 그룹이 스키마 왼쪽의 &#39;구성&#39; 창에 나열됩니다.

>[!WARNING]
>
>이러한 변경 사항은 저장되지 않습니다. 그냥 &#39;적용&#39;한 거예요 저장하지 않고 페이지에서 나가려면 작업을 잃게 됩니다. 이동하기 전에 이 섹션의 단계를 완료하십시오.

## 사용자 지정 장치 속성 만들기

이제 장치 XDM 개체가 생성되었으므로 장치별 필드 생성으로 이동할 수 있습니다.

1. 방금 만든 새 **장치** 개체 오른쪽에 있는 **+** 아이콘을 클릭하고 오른쪽 레일의 &#39;필드 속성&#39; 메뉴를 사용하여 제공된 값으로 다음 필드를 채웁니다.
   - 필드 이름: **만들기**
   - 표시 이름: **만들기**
   - 유형 드롭다운: **문자열**
   - 필드 그룹에 할당: **오퍼 세부 정보**(이미 선택되어야 함)
   - 모든 필드가 올바른지 확인했으면 파란색 **적용** 단추를 클릭하여 스키마에 적용된 변경 내용을 확인합니다
2. **모델** 및 **계층**&#x200B;에 대해 두 개의 특성을 더 추가하려면 이전 단계를 반복합니다. 동일한 이름 지정 패턴, 유형 및 필드 그룹을 사용합니다. 완료되면 스키마는 다음과 같이 표시됩니다.

   ![완료된 만들기, 모델 및 계층 필드를 표시하는 오퍼 스키마](assets/create-offer-attributes-make-model-tier-fields.png)

3. 모든 새 XDM 필드/특성을 만든 상태에서 오른쪽 상단의 **저장**&#x200B;을 클릭하면 화면 하단에 녹색 &quot;스키마를 저장했습니다&quot; 메시지가 표시됩니다. 이제 이 섹션의 단계를 완료했습니다.

>[!WARNING]
>
>업데이트한 스키마는 향후 모든 오퍼를 포함하여 모든 오퍼에 적용됩니다. 이 스키마에 속성을 추가할 때는 주의해야 합니다. 휴대폰을 판매하는 통신사의 예제 사용 사례에서 디바이스 제조사, 모델 및 계층 속성은 앞으로 몇 년 동안 여러 오퍼에 널리 사용될 수 있으므로 추가하는 것이 적절합니다. 오퍼에 필요한 속성을 고려할 때 특정 캠페인에 고유한 속성을 추가하지 마십시오. 몇 개월 또는 몇 년 동안 이 스키마가 확장되어 오퍼를 만들 때 문제가 발생할 수 있습니다. 오퍼를 만들 섹션에서 이 방식이 어떻게 적용되는지 확인할 수 있습니다.

## 요약

오퍼를 만들고 평가할 때 랩의 후반부에 활용할 재사용 가능한 사용자 정의 필드로 표준 오퍼 스키마를 업데이트했습니다.
