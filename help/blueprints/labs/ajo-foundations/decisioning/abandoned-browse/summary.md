# 요약

축하합니다. 실습을 완료했습니다! 이제 전체 **Adobe Journey Optimizer Decisioning 워크플로**&#x200B;를 빌드하고 테스트했습니다.

먼저 **오퍼 스키마**&#x200B;를 확장하고 **자격 규칙**&#x200B;을 만들어 특정 오퍼에 적합한 고객을 제어했습니다. 그런 다음 여러 **오퍼 항목**&#x200B;을(를) 만들고, 우선 순위 및 빈도 상한을 구성한 다음, 이를 **오퍼 컬렉션**(으)로 구성했습니다.

그런 다음 **등급 수식** 및 **선택 전략**&#x200B;을 만들어 의사 결정 중에 적합한 오퍼를 평가하고 우선 순위를 지정하는 방법을 결정했습니다. 또한 외부 시스템이 오퍼 결정을 요청하고 수신할 수 있도록 **CBE(코드 기반 경험) 채널**&#x200B;을 구성했습니다.

마지막으로 **엔드 투 엔드 의사 결정 흐름을 테스트했습니다**. Adobe Journey Optimizer이 프로필 데이터를 올바르게 평가하고, 의사 결정 논리를 적용하고, 적절한 오퍼를 반환하는지 확인합니다.
