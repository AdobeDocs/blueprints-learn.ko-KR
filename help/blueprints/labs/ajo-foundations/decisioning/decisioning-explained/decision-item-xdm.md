# 결정 항목 XDM

## 학습 목표

이 단원을 마치면 다음을 수행할 수 있습니다.

- 모든 의사 결정 항목에 사용되는 사전 빌드된 XDM 스키마 식별
- 스키마 내에서 사용자 지정 특성이 어디에 있는지, 그리고 그러한 특성에 적용되는 상한을 설명합니다
- 상위 오브젝트 아래에 중첩된 속성이 재사용을 지원하는 방법 인식

## 필요한 자료

- 12개 이상의 스티커 메모장(실수를 할 경우 더 많음)

## 강의

비디오 도중에 12개의 스티커 메모 상단에 4개의 속성 이름을 쓰도록 일시 중지합니다. 다음 단원에서 실제 값을 입력합니다.

>[!VIDEO](https://video.tv.adobe.com/v/3502206/)

## 주요 개선 사항

- 모든 의사 결정 항목은 동일한 사전 설치된 스키마(개인화된 오퍼 항목 - 경험 의사 결정)를 사용합니다
- \_experience 노드의 모든 항목은 시스템에 필요하며 편집할 수 없습니다.
- 사용자 지정 특성은 조직의 테넌트 네임스페이스에 있으며 스키마당 100개로 제한됩니다.
- 모든 의사 결정 항목에 대해 하나의 스키마만 있음 - 중복 또는 대체 버전 없음
