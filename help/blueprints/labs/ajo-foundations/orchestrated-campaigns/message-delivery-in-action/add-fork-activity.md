# 포크 활동 추가

## 목표

다음 단계 집합에서는 포크 활동을 캠페인에 추가하고 데이터의 동일한 분기를 만듭니다.

## 포크 활동

구성된 **빌드 대상**&#x200B;의 캔버스가 표시됩니다. 흐름 끝에서 **+**&#x200B;을(를) 클릭하고 흐름 제어 섹션에서 **포크** 활동을 추가합니다.

![포크 흐름 제어 활동을 캔버스에 추가](assets/add-fork-activity-add-fork-flow-control.png)

>[!NOTE]
>
>기본적으로 포크 활동은 항상 두 개의 분기를 만듭니다

## 요약

이제 캠페인 캔버스에서 포크 활동을 사용하여 유입되는 동일한 데이터의 동일한 분기를 만드는 것이 얼마나 쉬운지 확인했습니다. 포크 활동의 분기는 다음 단계에서 사용됩니다.

관심 있는 경우 [여기](https://experienceleague.adobe.com/ko/docs/journey-optimizer/using/campaigns/orchestrated-campaigns/design-campaigns/fork)에서 더 읽을 수 있습니다.
