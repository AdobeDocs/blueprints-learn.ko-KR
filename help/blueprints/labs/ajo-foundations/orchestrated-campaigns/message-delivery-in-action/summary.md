# 요약

이 실습을 통해 다음과 같은 활동을 수행했습니다.

- 오케스트레이션된 캠페인 구축
- 대상 작성 활동을 사용하여 기본 계획 멤버에 대한 대상을 작성합니다
- 대상을 포크하여 두 개의 분기를 만들고 각각 `Profile-Email` 및 `Relational-Email`의 전자 메일 채널을 사용하여 메시지를 보냈습니다.
- 구성된 두 이메일 채널 간의 동작 차이를 알아보기 위해 캠페인을 테스트했습니다

>
>**이 문서를 읽고 있으면 실습이 끝났음을 의미합니다.**
