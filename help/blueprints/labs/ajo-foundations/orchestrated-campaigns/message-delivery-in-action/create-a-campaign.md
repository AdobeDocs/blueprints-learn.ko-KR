# 캠페인 만들기

## 목표

다음 단계 세트에서는 오케스트레이션된 캠페인을 만드는 것으로 시작합니다.

## 캠페인 만들기

1. 왼쪽 레일에서 **캠페인**&#x200B;을 클릭합니다.

![왼쪽 레일에서 캠페인 클릭](assets/create-a-campaign-click-campaigns.png)

2. **캠페인 만들기**&#x200B;를 클릭합니다.

![캠페인 만들기 단추를 클릭합니다](assets/create-a-campaign-click-create-campaign.png)

3. **오케스트레이션 - 마케팅**&#x200B;을 선택하고 **확인**&#x200B;을 클릭합니다.

![오케스트레이션 - 마케팅 선택 후 확인 클릭](assets/create-a-campaign-select-orchestration-marketing.png)

4. 아래에 캠페인 세부 정보를 입력한 다음 완료되면 **저장 단추**&#x200B;를 클릭하십시오.
   - **이름:** `OC-MDL-Campaign-Test`
   - **설명:** `OC Message Delivery Test`

![캠페인 세부 정보를 입력하고 [저장]을 클릭하세요](assets/create-a-campaign-provide-campaign-details.png)

5. 계속하기 전에 확인 메시지를 기다립니다.

![캠페인 설정에서 확인 메시지를 업데이트했습니다](assets/create-a-campaign-confirmation-message.png)

## 요약

다음 단계 세트에서 사용할 모든 기본 설정을 구성한 오케스트레이션된 캠페인을 만들었습니다.
