# 사용 사례를 아키텍처에 매핑

## 학습 목표

이 실습이 끝나면 다음 작업을 수행할 수 있습니다.

- 구조화된 의사 결정 프레임워크를 적용하여 실제 마케팅 사용 사례를 평가합니다.
- 각 사용 사례를 지원하는 데 필요한 AJO 아키텍처 구성 요소 식별
- 적절한 오케스트레이션 엔진(오케스트레이션된 캠페인 또는 여정)을 선택하고 권장 사항을 정당화합니다
- 3가지 연결 5G 사용 사례에 대한 올바른 아키텍처 결정을 설명하고 각 사례의 신호를 명확히 설명합니다.

준비가 되면 비디오로 이동하여 랩 지침을 확인하십시오.
