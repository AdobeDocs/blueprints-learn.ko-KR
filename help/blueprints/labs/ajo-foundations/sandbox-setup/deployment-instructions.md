# 배포 지침

>[!WARNING]
>
>자신의 속도에 맞게 실습을 진행하는 경우에만 필요합니다. 라이브 교육 과정 또는 이벤트에 있는 경우 샌드박스가 이미 배포되었습니다.

AJO Architecture Foundations 랩 팩은 오케스트레이션된 캠페인에 사용되는 프로필 저장소 및 AJO 관계형 저장소를 모두 포괄하여 랩 전체에 사용할 스키마, 데이터 세트, 데이터 흐름 및 샘플 데이터를 생성하는 명령줄 도구인 DEP CLI를 사용하여 샌드박스에 배포됩니다.

## 배포되는 항목

**프로필 트랙**

- ID 네임스페이스(customerID, planID, productID)
- 프로필에 대해 활성화된 표준 XDM 필드 그룹, 설명자 및 스키마
- 프로필에 대해 카탈로그 데이터 세트 활성화됨
- 정책 및 대상자 병합
- 세 개의 샘플 데이터 세트에 대한 프로필 데이터: 차원 모드(트레이트 + 이벤트), 낯선 항목(트레이트) 및 의사 결정(트레이트)

**관계형 트랙**

- customerID ID 네임스페이스
- 기본 키, 외래 키 및 버전 설명자가 있는 11개의 관계형 XDM 스키마
- AJO 오케스트레이션된 캠페인에 대해 11개의 데이터 세트 활성화
- 11개의 데이터 흐름이 데이터 랜딩 구역에서 데이터 로드 중

>[!NOTE]
>
>엔드 투 엔드 배포에는 약 2시간 23분이 소요됩니다. 프로필 및 관계형 트랙은 동시에 실행되며, 대부분의 경우 CLI에서 자동으로 수행하는 무인 대기 시간입니다.

## 필요 조건

- **라이선스 권한.** Real-Time CDP(스트리밍 세그먼테이션 포함) 및 Adobe Journey Optimizer(오케스트레이션된 캠페인 포함)가 있는 IMS 조직에 대한 관리 권한
- **액세스 권한.** [Developer Console 설정](developer-console-setup.md)에서 만든 API 자격 증명을 포함하여 대상 샌드박스에 대한 모든 권한이 있는 Experience Platform 역할입니다.
- **Developer Console 자격 증명** Adobe Experience Platform API 및 Adobe Journey Optimizer API를 모두 포함하는 프로젝트. 아직 없으면 먼저 [Developer Console 설정](developer-console-setup.md)을(를) 따르십시오
- **샌드박스.** 배포를 시작하기 전에 최소 120분 동안 `dev` 유형의 비어 있고 &quot;준비&quot; 상태입니다.
- **Node.js.** Windows 또는 Mac의 모든 최신 LTS 버전

## &#x200B;1. CLI 설치

1. [dep-cli 저장소 복제 또는 다운로드](https://github.com/adobe/dep-cli)
1. `dep-cli` 디렉터리에서 `npm install` 실행
1. `npm start`(으)로 CLI 시작

>[!NOTE]
>
>위의 명령을 실행하려면 Node.js가 필요합니다. Node.js가 아직 설치되지 않은 경우 Wiki의 [Node.js 설정](https://github.com/adobe/dep-cli/wiki/Nodejs-Setup)페이지를 먼저 참조하십시오. 스크린샷과 기존 설치를 업데이트하는 방법을 포함한 전체 설치 세부 정보는 [설치](https://github.com/adobe/dep-cli/wiki/Installation)wiki 페이지를 참조하십시오

## &#x200B;2. 환경 파일 구성

CLI는 환경 파일이 가리키는 샌드박스에 배포되므로 이를 올바르게 설정한 후 실행해야 합니다.

1. `envFiles/sample-env.json`을(를) 복사하고 새 이름을 지정하십시오(예: `my-env.json`).
2. 파일을 열고 [Developer Console 설치](developer-console-setup.md)의 값을 사용하여 다음 필드를 채웁니다.

| **필드** | **값** |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `API_KEY` | 클라이언트 ID |
| `CLIENT_SECRET` | 클라이언트 암호 |
| `IMS_ORG` | 조직 ID |
| `SCOPES` | Experience Platform API 및 Adobe Journey Optimizer API 범위를 모두 포함해야 합니다&#x200B;<br />*(예: cjm.suppression\_service.client.delete, cjm.suppression\_service.client.all, openid, session, AdobeID, read\_organizations, additional\_info.projectedProductContext)* |
| `SANDBOX_NAME` | 타깃팅하는 샌드박스는 비어 있고 유형이 `dev`이어야 합니다. |

&#x200B;3. 파일 저장 및 닫기

>[!NOTE]
>
>CLI 명령을 실행할 때마다 이 파일의 이름을 입력하라는 메시지가 표시되므로 아래 단계에서 다시 사용할 수 있습니다.

## &#x200B;3. AJO Architecture Foundations 메뉴 실행

메인 메뉴에서 **AJO의 기초**&#x200B;을(를) 선택합니다. 두 트랙에 걸쳐 6개의 계단이 갈라져 있다.

### 프로필 추적(순서대로 실행)

>[!WARNING]
>
>1단계를 실행하기 전에 샌드박스가 최소 60분 동안 &quot;준비&quot; 상태에 있어야 합니다.

| **단계** | **기능** | **실행하기 전에** |
| ------------------------ | ------------------------------------------------------------------------------------------- | ---------------------------------- |
| &#x200B;1. 프로필 기반 만들기 | ID 네임스페이스, 스키마, 데이터 세트, 병합 정책 및 대상자 배포 | 샌드박스 &quot;준비&quot; - 60분 이상 |
| &#x200B;2. 프로필 데이터 로드 | 데이터 흐름을 만들고 Depeche 모드, Stranger Things 및 Decisioning 프로필 데이터 스트리밍 | 1단계 후 60분 이상 대기 |
| &#x200B;3. 프로필 상태 확인 | 모든 프로필 데이터가 올바르게 로드되었는지 확인합니다. | 2단계 후 15분 이상 대기 |

1단계는 약 2분, 2단계는 약 6분 정도 소요됩니다.

>[!NOTE]
>
>2단계는 오류가 발생하면 안전하게 재실행할 수 있습니다. 기존 트레이트를 덮어쓰고 중복 이벤트는 건너뜁니다.

### 관계형 트랙

>[!WARNING]
>
>샌드박스는 4단계 또는 6단계를 실행하기 전에 적어도 120분 동안 &quot;준비&quot; 상태여야 합니다.

| **단계** | **기능** | **실행하기 전에** |
| ----------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------- |
| &#x200B;4. 관계형 베이스 만들기 | customerID 네임스페이스 및 관계형 스키마/설명자/데이터 세트를 만듭니다. | 샌드박스 &quot;준비&quot; - 120분 이상 |
| &#x200B;5. 관계형 데이터 로드 | 11개의 CSV 파일을 업로드하고 로드하는 데이터 흐름을 만듭니다 | 4단계 직후 실행 — 수동 대기 필요 없음 |
| &#x200B;6. 관계형 기본 및 데이터 배포 | 4단계와 5단계를 결합하여 1회 ~5분 실행 | 샌드박스 &quot;준비&quot; - 120분 이상 |

>[!NOTE]
>
>단계 4와 5를 개별적으로 실행하는 대신 단계 6을 사용하십시오. 이 작업은 처리된 전달 대기와 동일한 작업을 한 번에 수행합니다.
> [!NOTE]
>
>위의 모든 대기 시간은 CLI에 의해 자동으로 확인됩니다. 단계를 너무 일찍 실행하면 단계가 차단되고 기다리는 시간을 알려줍니다.

## 문제 해결

>[!WARNING]
>
>**이벤트가 누락된 상태로 프로필 상태 검사가 실패합니다.** 일부 프로필 데이터의 전파가 아직 완료되지 않았습니다. 15분 더 기다린 후 프로필 상태 확인 을 다시 실행합니다. 그래도 실패하는 경우 프로필 데이터 로드 를 다시 실행하고 15분 정도 기다린 후 다시 확인합니다.

>[!WARNING]
>
>**관계형 데이터 로드가 중간에 실패했습니다.** 각 API 호출은 최대 3회 다시 시도합니다. 그래도 실패하는 경우 정리 를 통해 소스 연결, 타겟 연결 및 소스 연결이 생성된 데이터 흐름을 제거하므로 5단계(또는 6단계)를 완전히 다시 실행할 수 있습니다. API를 통해 매핑 세트를 삭제할 수 없으며 남겨 둘 수 있습니다. 이는 재배포에 영향을 주지 않습니다.

**다른 오류가 발생했습니다.** 마지막으로, CLI의 샌드박스 관리 메뉴에서 샌드박스를 재설정하고 1단계에서 재배포할 수 있습니다.

>[!CAUTION]
>
>샌드박스를 재설정하면 문제가 해결됩니다. 계속하기 전에 CLI에서 확인할 샌드박스 이름을 입력하라는 메시지가 표시됩니다.
