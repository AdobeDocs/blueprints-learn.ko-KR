# 사용 사례 #2 - 업셀

## 개요

이 비디오에서는 유료 및 DM 채널을 통해 데이터 사용량이 많은 고객을 타겟으로 하는 업셀 사용 사례에 접근하는 방법에 대해 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3459487/?quality=12&learn=on)



**사용 사례 정의**

지난 6개월 동안 총 청구 데이터 사용량이 140GB(평균 6개월) 이상인 모든 고객을 찾습니다. 월간 데이터 사용량 >=20GB 및 최종 전화 요금제가 없는 사용자

Facebook/Google 및 DM 채널에 활성화.

DM 개인화 필드:

- 인사말→ 사용되는 이름
- 메일링→ 사용되는 메일링 주소
- 메일링 →에 사용되는 플랜 이름(예: &quot;Eric, 오늘 최종 플랜으로 업그레이드!&quot;)



## 분석 작업

위의 내용을 분석하고 적어 두십시오.

1. 이 사용 사례를 해결하는 데 필요한 필드는 무엇입니까?
1. 평가 방법은 스트리밍이어야 합니까?
1. 청구 데이터에 유의해야 할 사항은 무엇입니까?
1. 다른 어떤 정보를 알고 싶으십니까?

기억하십시오. 비즈니스 이해 당사자로부터 요구 사항을 받으면 해당 요구 사항이 불완전하고 다른 용어를 사용하며 이를 모른 채 가정을 하는 경향이 있습니다. 그 많은 것을 수면 위로 끌어내고 그들에게 행해질 수 있는 어떤 것으로 인도하는 것은 여러분의 일입니다.



## 접근 방식

이 사용 사례에서는 다음 두 가지 옵션을 평가합니다.

- 옵션 #1(대상을 사용하여 집계)
  - 이렇게 하면 대상자가 합계를 수행합니다
    - 청구 데이터 사용량 합계 140GB(지난 6개월)
    - 청구 데이터 사용량 평균 20GB(지난 6개월)
    - 청구 데이터 사용량이 많지만 Ultimate 플랜은 없음
- 옵션 #2(사전 집계 사용)
  - 이렇게 하면 프로필에 데이터를 추가하기 전에 수행한 집계가 활용됩니다
    - 청구 데이터 사용량 높지만 Ultimate 플랜(Agg) 없음
