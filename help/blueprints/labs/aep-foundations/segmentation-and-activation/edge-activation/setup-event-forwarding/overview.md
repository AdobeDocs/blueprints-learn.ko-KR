# 이벤트 전달 설정

이벤트 전달은 Edge에 있으며, 이 기능을 통해 규칙 세트 및 가벼운 변환을 만들어 이벤트를 모든 엔드포인트에 보낼 수 있습니다.

이 단계에서는 Edge으로 보내는 모든 이벤트를 웹후크로 전달합니다. 웹후크는 제3자를 위한 대리 역할을 하게 되며, 어떤 일이 일어나고 있는지 알 수 있게 해 준다.

이를 구성하려면 다음을 설정합니다.

- 전달할 내용과 위치를 결정하는 데 필요한 모든 확장, 데이터 요소 및 규칙이 포함된 속성
  - 들어오는 이벤트를 참조하거나 필요한 경우 여러 개별 구성 요소로 구문 분석하는 데이터 요소
  - 전달할 내용, 페이로드를 변형하고 전송할 위치에 조건을 추가하는 규칙
- 활용할 서비스를 구성하는 데이터 스트림(예: 이벤트 전달 및 AEP)
  - 그런 다음 이러한 데이터스트림으로 전송된 데이터는 구성된 서비스에 따라 조치를 취할 수 있습니다(예: 이벤트를 전달하고 데이터를 데이터 세트로 전송)
