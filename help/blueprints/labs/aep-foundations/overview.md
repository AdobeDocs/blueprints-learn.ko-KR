# 개요

## 학습 내용

1. **NoSQL 변환에 관계:**
   - 실시간 고객 프로필의 아키텍처, 모델링 및 어셈블리 이해
   - 실시간 고객을 모델링하기 위한 가상의 시나리오에 LID 방법론 적용
1. **XDM(경험 데이터 모델):**
   - XDM의 구성 요소와 실시간 고객 프로필 비헤이비어와의 관련성에 대해 알아봅니다.
   - UI 및 API를 모두 사용하여 스키마 빌드를 실습합니다
1. **데이터 수집 및 프로필 만들기:**
   - Adobe Experience Platform의 다양한 데이터 저장소를 구분합니다
   - 일괄 처리 및 스트리밍 소스에 대한 데이터 처리에 대해 알아보기
   - 데이터를 수집하고 프로필을 만드는 실습형 랩
1. **세분화/활성화 및 대상자 구축:**
   - 실시간 고객 프로필에서 지원하는 세그먼트 평가 양식 이해
   - 허브와 Edge 프로필 기능 차별화
   - 스트리밍 대상 작업을 포함하여 UI에서 대상을 빌드하고 활성화합니다



## 타겟 대상자

- 솔루션 설계자
- 엔터프라이즈 아키텍트
- 개발자
- 데이터 엔지니어
- 데이터 설계자



## 권장 경험 또는 친숙도

- 데이터베이스 개념(만들기, 업데이트, 삭제)
- 데이터 모델링 개념(행, 필드, 키 등)
- REST API 작업
- Adobe Experience Platform에 대한 일반적인 이해
- CDP, 광고 기술, CRM 또는 기타 마케팅 기술 스택에 대한 노출


## 소개

이 비디오에서는 Adobe에서 규모에 맞는 개인화가 무엇을 의미하는지, 그리고 왜 대상자 또는 그룹 기반 타깃팅을 넘어서는 것이 진정으로 개인화된 고객 경험을 제공하는 데 핵심적인지에 대해 설명합니다.
