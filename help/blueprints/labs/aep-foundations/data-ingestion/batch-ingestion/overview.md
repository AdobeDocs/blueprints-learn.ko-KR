# 일괄 처리 수집

## 학습 목표

이 연습에서는 파일 기반 소스 커넥터의 고객 계정 데이터를 AEP 데이터 레이크와 프로필로 로드합니다. 다음 내용을 학습하게 됩니다.

1. 통과 매핑 이해
1. ML에서 생성한 패스스루 매핑 수정
1. 소스 데이터 미리보기를 사용하여 데이터 품질 문제 확인
1. 데이터 흐름 실행 예약
1. 필수 필드의 누락 값에서 발생하는 오류 처리
1. 데이터 유형 불일치 오류로 인해 발생하는 오류 처리
1. 데이터 수집 오류 처리 및 장애 복구
1. 테스트 데이터를 반복적으로 사용하여 포괄적인 매핑 세트를 생성합니다.

>[!NOTE]
>
>이전 실습에서 고객 계정 스키마 만들기를 완료하지 않은 경우 스키마 카탈로그를 검색하여 대신 **dep: 고객 계정**&#x200B;을 사용할 수 있습니다.
