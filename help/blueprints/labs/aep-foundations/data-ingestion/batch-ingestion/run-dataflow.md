# 데이터 흐름 실행

모든 것이 제대로 보이면 계속하고 오른쪽 상단의 **마침** 단추를 클릭하여 데이터 로드를 실행하십시오.

**완료**&#x200B;를 클릭하면 **데이터 흐름** 화면으로 돌아갑니다. 데이터 흐름을 만드는 데 몇 분 정도 걸릴 수 있습니다. 첫 실점은 몇 분 후에 시작될 것이다.

새로 만든 데이터 흐름 및 실행 상태를 표시하는 ![데이터 흐름 화면](assets/run-dataflow-dataflows-sources-screen.png)

>[!NOTE]
>
>백엔드가 업데이트를 UI에 푸시하지 않으므로 상태 업데이트를 보려면 페이지를 계속 새로 고쳐야 합니다.

>[!NOTE]
>
>모든 경고를 켜면 브라우저의 오른쪽 상단 모서리에 있는 브라우저에서 흐름이 시작되고 성공적으로 완료되거나 실패할 때 경고를 받습니다
