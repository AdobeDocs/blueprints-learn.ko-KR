# 스트림 수집

## 학습 목표

이 연습에서는 스트리밍 소스에서 Adobe Experience Platform 데이터 레이크 및 프로필로 고객 계정 데이터를 로드합니다. 이 실험실을 가지고 나면 뭘 가지고 가셔야 하죠?

- 스트리밍 인렛 만들기
- 다른 데이터 흐름에서 매핑 세트를 가져오는 중
- UI에서 데이터 흐름 ID 및 데이터 세트 ID를 가져오는 중
- REST API를 사용하여 이벤트 수집

>[!NOTE]
>
>이전 실습에서 고객 계정 스키마 생성을 완료하지 않은 경우 스키마 카탈로그를 검색하여 대신 **dep: 고객 계정**&#x200B;을 사용할 수 있습니다.
