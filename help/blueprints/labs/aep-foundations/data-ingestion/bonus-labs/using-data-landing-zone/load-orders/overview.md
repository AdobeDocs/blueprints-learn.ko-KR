# 주문 로드

## 랩 개요

이 실습에서는 복잡한 데이터 변환 및 JSON 데이터 처리를 소개합니다.

## 학습 목표

이 연구소에서 얻을 수 있는 주요 교훈은 무엇입니까?

- 중첩 JSON 데이터의 일괄 처리 수집 이해
- 복잡한 비 XDM 필드와 XDM 간의 필드 매핑을 단순화하려면 개념으로 개체 사본을 사용하십시오.
