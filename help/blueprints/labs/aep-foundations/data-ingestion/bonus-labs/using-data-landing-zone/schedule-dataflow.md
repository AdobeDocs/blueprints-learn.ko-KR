# 데이터 흐름 예약

**예약** 단계:

1. **빈도**&#x200B;을(를) 분으로 설정합니다.
1. **간격**&#x200B;을(를) 15분(15분)으로 설정합니다.
1. **다시 채우기** 옵션을 설정합니다.

>[!NOTE]
>
>**시작 시간**&#x200B;은(는) UTC입니다.
>
>UTC(협정 세계시)는 전 세계 시간 관리를 위한 기준점으로 사용되는 글로벌 시간 표준입니다. 전역으로 분산된 팀에게는 다양한 지역 및 국가에 대한 공통 참조를 제공하므로 다양한 시간대에 걸쳐 활동을 조정하고 이벤트를 예약하는 것이 더 쉽습니다.
>
>AEP UI의 다양한 부분에서 시간 예약의 기반으로 UTC 시간이 표시됩니다. UTC 시간은 런던 시간보다 1시간 늦습니다. UTC 시간이 확실하지 않다면 &quot;UTC time now&quot;를 검색하십시오.

>[!NOTE]
>
>실제로 **다시 채우기** 옵션은 모든 파일을 한 번만 다시 채우며 후속 실행에서는 새 파일을 가져옵니다.

![빈도, 간격 및 채우기 옵션이 설정된 데이터 흐름 실행 예약](assets/schedule-dataflow-scheduling-dataflow-run.png "데이터 흐름 실행 예약")

데이터 흐름을 검토하고 **완료를 클릭합니다.**

![마침을 클릭하기 전에 최종 데이터 흐름 구성 검토](assets/schedule-dataflow-review-final-dataflow.png "최종 데이터 흐름 검토")

>[!CAUTION]
>
>데이터 흐름에 대해 **한 번 실행** 옵션을 선택하면 이 일정을 편집하거나 나중에 데이터 흐름을 업데이트할 수 없습니다. 그러나 필요에 따라 데이터 흐름을 실행할 수 있습니다. 즉, 새 데이터를 수집해야 하는 경우 다시 실행할 수 있습니다.

**완료**&#x200B;를 클릭하면 **데이터 흐름** 화면으로 돌아갑니다. 데이터 흐름을 만드는 데 몇 분 정도 걸릴 수 있습니다. 마지막 데이터 흐름 실행 상태는 **실행 없음**&#x200B;을 나타냅니다. 첫 실점은 몇 분 후에 시작될 것이다.

![실행 안 함 상태의 새 데이터 흐름을 보여 주는 데이터 흐름 화면](assets/schedule-dataflow-dataflows-screen-no-runs-status.png "데이터 흐름 소스 화면")

&#x200B;> [!NOTE]
>
>백엔드가 업데이트를 UI에 푸시하지 않으므로 상태 업데이트를 보려면 페이지를 계속 새로 고쳐야 합니다.

>[!NOTE]
>
>모든 경고를 켜면 브라우저의 오른쪽 상단 모서리에 있는 브라우저에서 흐름이 시작되고 성공적으로 완료되거나 실패할 때 경고를 받습니다
