# 실패한 데이터 흐름 다시 시도

워크플로우를 다시 시도하려면 다음 작업을 수행하십시오.

1. **원본 -> 데이터 흐름 -> \[데이터 흐름 이름] -> \[실행 실패]**(으)로 이동
1. 올바른 레일을 가져오지 못한 데이터 흐름 실행을 강조 표시합니다.
1. **다시 시도**&#x200B;를 클릭합니다. 다시 시도하면 실패한 실행과 연결된 데이터의 복사본이 복사되고 이제 새 매핑 규칙이 적용됩니다.

![오른쪽 레일에서 실패한 데이터 흐름 실행 다시 시도](assets/retry-a-failed-dataflow.png)

>[!NOTE]
>
>실패한 데이터 흐름을 다시 시도하면 새 데이터 흐름이 만들어지고 실행됩니다. 데이터 흐름 목록의 맨 위에 나타납니다
