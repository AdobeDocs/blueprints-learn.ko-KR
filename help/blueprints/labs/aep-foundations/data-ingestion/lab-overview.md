# 랩 개요

## 목표

이러한 실습의 목표는 데이터 수집의 실질적인 문제를 처리할 수 있도록 준비하는 것입니다. 이러한 이해를 바탕으로 프로덕션의 데이터 구현에 대해 팀을 처리, 관리 및 안내할 수 있습니다. 이론의 매혹적인 만큼이나, 우리는 문제들이 다가올 때 문제를 디버깅하는 데 시간을 할애하고 도구에서 보는 것을 이 부트캠프에서 배운 더 광범위한 개념의 그것과 연결할 것입니다.



## 기대 사항

집중이 필요해 이유는 다음과 같습니다. 데이터는 모든 구현의 기초가 됩니다.

데이터 문제는 쉽지 않습니다. 데이터는 지저분하고 불완전하며 흩어져 있어 필요한 시스템으로 가져오기가 어렵습니다. 이 실험실들은 여러분에게 그 시나리오들을 맛볼 수 있도록 고안되었습니다.

이러한 다음 실험실은 시스템 내부를 만질 때 관심과 헌신이 필요할 것입니다. 당신이 모든 개념을 한 번에 흡수하고 실험실에서 자신의 길을 찾는 시간을 갖는 것은 예상되지 않는다.



## 요점

소스 스키마가 있고 XDM에서 대상 스키마를 정의했으므로 매핑을 통해 두 스키마를 연결해야 합니다. 이 프로세스에는 필드별 필드 매핑이 필요하므로 몇 가지 일반적인 위험을 인식하면서 프로세스를 가속화하는 몇 가지 기술을 학습해야 합니다.

- 통과 매핑 이해
- AI/ML에서 생성된 패스스루 매핑 수정
- 소스 데이터 미리보기를 사용하여 데이터 품질 문제 확인

스키마 매핑이 설정되면 작업을 테스트하고 오류와 경고를 디버그해야 합니다.

- 데이터 흐름 실행 예약
- 프로필에 대한 데이터 세트 표시
- 필수 필드의 누락 값에서 발생하는 오류 처리
- 데이터 유형 불일치 오류에서 발생하는 오류를 처리합니다.
- 데이터 수집 오류 처리 및 장애 복구
- 테스트 데이터를 반복적으로 사용하여 포괄적인 매핑 세트를 생성합니다.
- 성공적으로 수집된 데이터를 확인하고 확인합니다.

위 개념은 관계형 및 비관계형 데이터 수집 시나리오와 함께 학습합니다.
