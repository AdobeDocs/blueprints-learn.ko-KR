# 강의

Adobe Experience Platform에서 데이터 수집에는 일괄 처리와 스트리밍의 두 가지 주요 패턴이 있습니다. 일괄 처리 수집에는 예약된 간격으로 대량의 데이터를 업로드하는 작업이 포함되며, 스트리밍 수집은 이벤트가 발생할 때 실시간으로 데이터를 가져옵니다. 이러한 패턴을 이해하는 것은 기업이 데이터를 플랫폼에 가져올 수 있는 적절한 속도와 방법을 선택하는 데 도움이 되므로 마케팅 경험이 적시에 적절하고 적절하며 비즈니스 요구에 부합할 수 있기 때문에 중요합니다.



## 데이터 수집 아키텍처

이 비디오에서는 소스 커넥터가 데이터 준비를 통해 데이터 레이크 및 실시간 고객 프로필로 데이터를 이동하는 방법을 포함하여 일괄 처리 및 스트리밍 데이터 수집 배후에 있는 아키텍처에 대해 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3459101/?quality=12&learn=on)





## 데이터 흐름 프레임워크

이 비디오에서는 수집을 확인하는 데 사용되는 형식 선택 사항 및 모니터링 단계와 함께 데이터 흐름을 구성하는 계정, 데이터 흐름 및 매핑에 대해 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3459103/?quality=12&learn=on)





## 복잡한 데이터로 데이터 준비

이 비디오에서는 데이터 준비에서 필드를 일대일로만 매핑할 수 있으며 목록을 단독으로 작성할 수 없으므로 복잡한 목록 데이터를 배열 또는 맵으로 모델링하고 수집하는 방법에 대해 알아봅니다.
