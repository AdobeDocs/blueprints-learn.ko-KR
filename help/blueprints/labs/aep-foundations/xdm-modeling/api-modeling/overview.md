# API 모델링

## 랩 개요

Experience Platform API를 사용하여 작업하는 것은 플랫폼의 다양한 기능을 자동화하고 운영하는 방법을 이해하는 데 중요합니다. 스키마를 정의하고 해당 스키마에서 데이터가 어떻게 설명되는지 이해하는 것은 데이터 아키텍처를 정의할 때 고객이 Adobe Experience Platform에서 가장 먼저 수행해야 하는 작업 중 하나입니다.

이 랩에서는 API만 활용하는 Adobe Experience Platform 스키마 디자인 환경에 대해 소개합니다. 기존 XDM 구성 요소를 활용하여 고유한 스키마를 만들고, XDM에 사용자 지정 항목을 추가하고, 실시간 고객 프로필과 함께 사용할 다양한 ID 설명자를 식별하고 만드는 방법을 알아봅니다.

## 학습 목표

다음과 같은 다양한 XDM 기본 구성 요소를 통해 Experience Platform API만 활용하는 스키마를 빌드할 수 있습니다.

1. 클래스
1. 필드 그룹
1. 설명자
   1. ID(기본 포함)
   2. 관계
   3. 참조
