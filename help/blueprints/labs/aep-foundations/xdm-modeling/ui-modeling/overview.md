# UI 모델링

## 소스를 XDM에 매핑

종이에 기재한 내용을 번역하여 경험하고 XDM **standard** 개체 및 필드를 검색하고 매핑하는 방법과 **사용자 지정** 개체 및 필드를 만드는 방법을 알아보세요.

다음을 통해 수행할 작업:

- Experience Data Model 개념의 실제 모습에 대한 UI 지식
- **XDM 필드 그룹**&#x200B;의 컨텍스트에서 개체 및 필드를 정의하는 방법을 이해합니다.
- 스키마 UI를 사용하여 XDM 표준 필드 그룹을 탐색하는 방법을 이해합니다



## UI를 통해 XDM 빌드

LID 방법론을 사용하여 생성한 스키마를 활용하는 연결 5G 고객 계정 스키마 구축 실습

다음을 통해 수행할 작업:

- 전체 스키마 구성 UI에 대한 기본 이해
- 스키마에 XDM 표준 필드 그룹을 추가하는 방법 알아보기
- XDM 표준 필드 그룹에서 불필요한 필드를 제거하는 방법 알아보기
- 스키마에서 사용자 정의 필드 그룹을 만들고 사용할 수 있습니다.
- 스키마 개발 😄 중에 자주 저장하는 방법을 배웁니다.
- 열거형과 제안 값의 차이점 이해



## 프로필에 대해 구성

ID 표시부터 조회 스키마에 대한 관계 설정에 이르기까지 실시간 고객 프로필과 함께 사용할 스키마를 구성하는 데 필요한 단계를 알아봅니다.

다음을 통해 수행할 작업:

- 필드를 ID 또는 기본 ID로 표시할 수 있습니다
- 두 스키마 간의 관계 구축
- 프로필에 대해 활성화하기 전에 스키마를 **테스트**&#x200B;해야 하는 이유를 이해합니다.
- **유니온 스키마**&#x200B;를 이해하고 시각적으로 확인할 수 있습니다.
