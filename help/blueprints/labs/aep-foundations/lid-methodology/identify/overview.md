# 식별

## 학습 목표

LID 방법론 내의 **Identify** 단계는 두 부분으로 구분됩니다.

1. 1부 - 나머지 테이블 유형 -> 레이블이 지정되지 않은 나머지 테이블을 식별하고 비정규화 유형에 레이블을 지정합니다.
1. 2부 - 주요 필드 -> 기본 및 지원 엔티티 모두의 주요 필드 식별



실시간 고객 프로필을 디자인하는 데 필요한 관계형 모델 내의 다음 항목을 식별하는 데 도움이 됩니다.

- Bridge 테이블(다대다 관계를 처리하는 테이블)
- 비정규화가 필요한 표
- 실시간 고객 프로필 내의 기본 ID
- 개인을 고유하게 식별하는 데 사용할 수 있는 기본 엔터티 클래스 내의 개인 기반 ID
- 개별 프로필/경험 이벤트 테이블 및 관련 조회 테이블 간의 관계 식별자
- 경험 이벤트 스키마에 필요한 필수 필드
- 개별 프로필 및 조회 스키마에 대한 권장 필드
