# 2부 - 주요 필드

## 강의

이 비디오에서는 각 테이블의 기본 ID, 개인 ID 및 관계 ID와 경험 이벤트에 필요한 _id, 타임스탬프 및 이벤트 유형 필드를 식별하는 방법에 대해 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3459085/?quality=12&learn=on)



## 랩 세부 정보

### ID 필드

- **개인 ID** - 개인을 고유하게 식별하는 데 사용됩니다. 기본 엔티티 테이블에서만 사용됩니다. 이 중 적어도 하나는 있어야 하지만 하나 이상이 있을 수 있습니다.
- **관계 ID(즉, 비개인)** - 실시간 고객 프로필의 기본 엔터티 테이블에서 연결된 지원 엔터티 클래스(즉, 조회)로의 관계를 설명하는 데 사용됩니다.
- **기본 ID** - 저장소 키로 사용되고 실시간 고객 프로필에서 사용 중인 모든 스키마에 필요한 개인 ID 또는 관계(비개인) ID일 수 있습니다. 기본 엔티티 테이블의 경우 ID도 개인을 고유하게 식별합니다. XDM 프로필 스키마 및 조회 스키마에 대해 이 필드를 지정하면 새 레코드가 생성되는지 또는 기존 레코드가 업데이트되는지 여부가 결정됩니다. 이 중에 정확히 하나가 있을 거예요

### 필수 필드(XDM 경험 이벤트만 해당)

- **\_id** - 실시간 고객 프로필이 기본 ID와 함께 사용하여 이벤트에 대한 고유한 저장소 키를 만듭니다. 프로필 서비스 내에서 이벤트 데이터가 우발적으로 중복되지 않도록 하는 데 필요합니다.
- **타임스탬프** - 모든 이벤트는 특정 시간에 발생하므로 모든 이벤트에는 타임스탬프가 필요합니다.

필수는 아니지만 권장되는 사항:

- **이벤트 유형** - 이벤트 데이터의 높은 수준의 동작(예: 구매, 예약 예약 등)을 설명합니다.

### 일반 규칙

1. Bridge 테이블 규칙 #2 - &quot;**P**&quot; 또는 &quot;**E**&quot; 상위(즉, 상위 테이블)와 &quot;**L**&quot; 테이블 사이에 브리지 테이블이 있는 경우 브리지 테이블을 상위 테이블의 일부로 처리합니다
1. 데이터 수집 중 재작업을 방지하기 위해 이 단계에서 **단일** 사용자에 대해 ID가 고유한지 항상 확인
1. 경험 이벤트 스키마의 경우 기본 ID는 한 사람에게 해당 동작을 고유하게 식별하는 것입니다.
1. 조회 테이블의 경우 관계형 모델의 기본 키(PK)는 항상 비개인 기본 ID입니다

**&quot;P&quot;, &quot;E&quot; 또는 &quot;L&quot;,**(으)로 레이블이 지정된 연결 5G Warehouse ERD 및 스트리밍 ERD의 각 테이블에 대해 이제 아래 단계를 수행하여 지정된 스키마 클래스에 대한 기본 ID, 개인 ID, 관계 ID 및 필수 필드를 식별합니다.

## 1단계 - XDM 개별 프로필 테이블의 레이블 키 필드

고객 계정 테이블 내의 주요 필드를 식별하려면 아래 단계를 수행하십시오.

- 기본 ID로 사용할 필드를 식별하고 `PI`(으)로 레이블을 지정합니다.
- 다른 모든 개인 ID를 식별하고 `I`(으)로 레이블을 지정합니다.
- 관계 ID를 식별하고 `R`(으)로 레이블을 지정합니다.



## 2단계 - XDM 경험 이벤트 테이블의 레이블 키 필드

1단계에서 수행한 것과 동일한 작업 세트를 이제 XDM 경험 이벤트 테이블에 대해 수행합니다.

- 기본 ID가 될 각 테이블의 필드를 식별하고 `PI`(으)로 레이블을 지정합니다.
- 각 테이블에서 다른 모든 개인 ID를 식별하고 `I`(으)로 레이블을 지정합니다.
- 모든 관계 ID를 식별하고 `R`(으)로 레이블을 지정합니다.

위의 레이블 외에도 다음 레이블을 지정합니다.

- 각 XDM 경험 이벤트 테이블에 대한 고유 이벤트 ID를 식별하거나 만들고 `_id`(으)로 레이블을 지정합니다.
- 각 테이블에 대한 이벤트의 타임스탬프를 식별하고 `T`(으)로 레이블을 지정합니다.
- 각 테이블에 대한 이벤트 유형을 식별하거나 만들고 `ET`(으)로 레이블을 지정합니다.



## 3단계 - 조회 테이블의 레이블 키 필드

각 조회 테이블에서 기본 ID가 될 필드를 식별하고 `PI`(으)로 레이블을 지정합니다
